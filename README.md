\# Day 01 - C++ Reconstruction



\## Project



Student score management program.



\## Functions



\- Input the number of students

\- Store names and scores

\- Calculate average score

\- Find the highest score

\- Output scores with two decimal places



\## C++ concepts practiced



\- string

\- array

\- function

\- pointer

\- dynamic memory

\- new / delete\[]

\- input / output

\- fixed / setprecision



\## Problems I encountered



1\. I did not know how to store multiple student names.

2\. I did not know how to create a dynamic array based on `num`.

3\. I confused `score` with `score\[num]` when passing the array to a function.

4\. I forgot how to use `setprecision`.

5\. I realized that I could understand C++ code better than I could write it independently.



\## What I learned



A program should start from:



Problem  

→ Data  

→ Data organization  

→ Operations  

→ Functions  

→ Code  

→ Debugging  

→ Result
